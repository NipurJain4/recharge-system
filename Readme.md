GitHub Pages Static Website
This project is a simple static website hosted using GitHub Pages. It contains an index.html file and optional CSS styling for customization.
Steps to Create and Host the Website
1.	Create an index.html file.

 ![Screenshot of index.html code](images/screenshot1.png)
2.	Push the file to a new GitHub repository.
3.	Go to your repository → Settings → Pages.
4.	Enable GitHub Pages.
5.	Select the 'main' branch and root folder.
6.	Access the live website from the link provided by GitHub.
![Screenshot of repo](images/screenshot2.png)
7.	Customize the design using CSS.

## 💡 What I Learned
- How to create and push HTML files to GitHub.
- How to enable GitHub Pages to host static websites

Notes
You can update your index.html and CSS files anytime. Changes will automatically reflect on the live website after pushing updates to GitHub.
